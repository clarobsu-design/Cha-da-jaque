# Chá da Jaque

## Publicar no GitHub Pages
1. Crie um repositório público chamado `cha-da-jaque`.
2. Envie `index.html` para a raiz do repositório.
3. Abra Settings > Pages.
4. Em Build and deployment, selecione `Deploy from a branch`.
5. Escolha `main` e `/ (root)` e clique em Save.
6. Aguarde o link aparecer na página Pages.

## Personalizar
O WhatsApp está no início do JavaScript, em `const whatsapp = "5544988034377";`.
A lista está no array `gifts`.

## Limitação
GitHub Pages hospeda apenas arquivos estáticos. O botão envia a escolha pelo WhatsApp; não existe reserva compartilhada nem bloqueio automático de itens. Os endereços de lojas são sugestões iniciais e devem ser confirmados antes de divulgar.
